# Serial Modem

The Serial Modem contains the Serial Modem application firmware for nRF91 based devices, and is built on [nRF Connect SDK](https://www.nordicsemi.com/Products/Development-software/nRF-Connect-SDK) (NCS).
It also includes some host examples.

You can find the documentation in the [Serial Modem](https://nrfconnectdocs.nordicsemi.com/addons/addon-serial_modem/latest/main/index.html) documentation.
